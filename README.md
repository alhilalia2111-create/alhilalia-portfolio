# Alhilalia Portfolio

Professional portfolio website built with ASP.NET Core MVC and C#.

## Features
- Modern one-page personal portfolio design
- Arabic + English friendly structure
- Responsive layout for desktop and mobile
- Sections for About, Vision, Skills, Projects, Education, and Contact
- Clean, professional UI with dark glassmorphism design

## Run locally
```bash
dotnet restore
dotnet build
dotnet run
```

Then open:
- https://localhost:7077

## Project structure
- `Controllers/HomeController.cs`
- `Models/PortfolioData.cs`
- `Views/Home/Index.cshtml`
- `Views/Shared/_Layout.cshtml`
- `wwwroot/css/site.css`
